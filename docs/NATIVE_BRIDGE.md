# HX87 native realization layer

HX89 has two native mechanisms with different purposes.

## NATIVE_ACCEL  -  canonical accelerator path

`NATIVE_ACCEL` proves that HX87 semantics, not raw host instructions, are authoritative.

A trigger cell stores the number of immediately following IR cells in `a`. The allowed IR cells are `NIMM`, `NADD`, `NXOR` and `NMUL`. HX87 walks those cells through the active five-dimensional direction, hashes the semantic IR, emits a deterministic x86-64 realization, hashes the generated bytes and performs this lifecycle:

```text
HX87 IR -> transient code buffer -> RW page -> copy -> RX -> execute
        -> result -> remove X -> unmap -> exact surreal integer
```

No generated code is stored in a snapshot. The semantic IR cells are persisted; the host realization can always be regenerated.

The shipped `polyforms/native_accel.hx` computes `(40 + 2) * 3 XOR 4 = 122` through this path.

## NABI0  -  literal-byte research facet

The earlier `NATIVE_RAW` facet remains for the narrower code/data experiment. It accepts only straight-line EAX arithmetic plus final `RET`:

- `90`  -  NOP
- `b8 imm32`  -  MOV EAX, imm32
- `05 imm32`  -  ADD EAX, imm32
- `2d imm32`  -  SUB EAX, imm32
- `35 imm32`  -  XOR EAX, imm32
- `69 c0 imm32`  -  IMUL EAX, EAX, imm32
- `c3`  -  RET, required final byte

Memory addressing, arbitrary branches, calls, privileged instructions and `SYSCALL` are rejected. Both mechanisms use W^X; neither creates an RWX mapping.
