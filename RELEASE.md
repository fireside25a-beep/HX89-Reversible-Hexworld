# HX89 scientific release

HX89 is a deterministic machine that transports exact observations of a reversible lattice gas. The complete route is gas density image → canonical Polyform → Bell 202 audio → HX0 reconstruction → HX89 execution → identical image bytes on the certified fixture. A separate gas certificate establishes microscopic reciprocity and echo; the CRTC module classifies the condition needed for a correlated transport circle while leaving its physical survival open.

The `lean/` directory contains a compiled Lean 4.30.0 proof of the local collision table and the conditional algebraic echo theorem. It does not replace the C/Python certificate for concrete torus indexing. `visualization/chiral_transport/` contains the original interactive Three.js/WebXR companion; `docs/assets/` contains the three original HX89 SVG diagrams.

## Verified machine and transport results

The canonical byte compiler maps payload bytes to ordered `EMIT` cells followed by `HALT`. The composition suite checks the complete 0 through 255 byte alphabet, Bell 202 transport through HX0, deterministic recompilation, the zero-length case, the 4095-byte arena boundary, and rejection above that boundary. The result is a semantic right inverse for the canonical emitted class, not an invertibility claim for arbitrary Polyform formatting.

The deterministic gas has exact finite-state reciprocity identities. With the implemented step operator, axial reflection, velocity reversal, and collision-dressed reversing involution, the suite checks the local identities and certifies the complete 2 x 2 torus state space for both chiralities. The exhaustive global certificate covers 16,777,216 occupation states. A separate oracle checks larger tori, multiple echo times, and the exact rank-three one-body linear collision-invariant space corresponding to mass and two momentum components.

The entropy Polyform terminates on explicit sparse-field endpoints. Seed 12345 reaches `(0,0,0,0,2)` as an intentional `HALT`, and all ten signed five-axis exits are covered by regression tests. Missing sparse cells outside the defined program remain execution errors.

The zero-field chiral FHP viscosity relation is treated as a molecular-chaos result inherited from the cited literature. The repository independently reconstructs the local 64-state collision map, obtains the published shear eigenvalue, and checks the resulting transport-circle identity exactly. The machine-level transport suite checks 3,575 exact rational parameter triples; the CRTC module separately checks 9,595 exact rational response points.

## Response-rigidity result

For every nonzero complex response `Z` with the stated real parity-symmetric anchor, the CRTC module proves that membership in the anchored circle is equivalent to constancy of `Re(1/Z)`. For a two-component shear block with `C6` covariance, the commutant has the form `aI+bJ`; symmetry fixes this two-coordinate form but does not force the dissipative coordinate `a` to remain constant.

An exact stationary Ornstein-Uhlenbeck Green-Kubo family provides a positive-dissipation counterexample in which the real inverse-response coordinate drifts and the anchored circle fails by the derived defect formula. This establishes that the stated symmetry and positivity assumptions do not by themselves protect the circle.

The fully correlated chiral FHP Green-Kubo problem remains open. The repository does not claim that the circle survives correlated FHP dynamics and does not claim an established Ward identity protecting it.

## Reproducibility

The principal verification command is:

```sh
make verify-all
```

It rebuilds the machine, runs the executable and sanitizer suites, regenerates evidence, verifies the CRTC module, rebuilds the scientific registries and documents, independently rederives the central mathematics, checks prose and citations, and runs the repository-wide equation and claim consistency audit.

The generated evidence is under `evidence/`. Machine-readable scientific claims and canonical equations are under `scientific/`. The thesis, companion, and short paper are built into `dist/` from sources under `thesis/` and `research/crtc/paper/`.

The public scientific boundary is recorded in `SCIENTIFIC_STATUS.md`, `docs/THEOREM_STATUS.md`, and `scientific/claims.json`.
